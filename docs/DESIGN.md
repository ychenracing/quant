# 科技趋势策略设计与研究合同

仅研究 A 股科技标的，数据起点不得早于 2023-01-01。目标是提高趋势捕获、风险响应和去龙头后的稳健性，不把未经检验的目标写成保证。

## 架构

采用单一现金账户，分离数据与证券规则、因果指标、持仓决策、风险状态、成交记账及研究报告。保留四套来源的有效思想：多通道趋势证据、多周期动量排序、盈利在位持仓保护、分层风险与恢复。避免复制四个独立账户或累加所有开关。

收盘信号最早下一可交易日开盘执行。交易量约束只读取前一日及以前的可用成交量。禁止按已知的未来大跌日期清仓、当天收盘信号当天成交、用缺失行情虚构成交或把合成数据作为真实经济证据。

## 验证

统一本金、行情、复权与成本；保留原生策略口径与统一成交口径的区别。正式对比必须有原生代码或经核验的适配器，近似复现不得冒称原项目。按完整连续账户拆分收益，另列独立冷启动区间。报告每池收益、回撤、订单数、换手、风险状态/行动延迟、去个股/去行业和固定随机子集结果。

任何失败、缺失标的、日期缺口、数据口径限制均写入结果。源码和样本已经被反复研究，不把历史窗口称为未经观察的样本外。全体组合最优和未来风险最早识别不由有限回测保证。

## 实施

1. 冻结四来源版本，审查实际选股、卖出与执行调用链，建立行情清单。
2. 先验证因果性、资金、T+1、证券单位、不可成交与缺失数据；再实现最小内核。
3. 用固定参数和有限备选比较，不针对 2026 崩跌窗口逐日拟合；保存所有候选结果。
4. 运行完整可获得历史和泛化矩阵，生成可重跑的交易、权益和诊断证据。
5. 校验文档、打包与必要快速测试；提交至 main 并读回 SHA。

研究获取工作流只在研究分支特定文件变化时触发，限时五分钟，不是 main 的常规门禁。常规 CI 只做离线快速正确性检查，不在每次推送重跑经济矩阵。
