# 架构、策略与参数

## 职责与依赖方向

`data → features → strategy → engine → evidence / cli`。`Config` 是不可变全局配置。生产包位于 `src/techquant`；`research/` 只承担选优、有限评估、外部对照和证据出版，不参与盘后决策。

|模块|职责|不负责的事情|
|---|---|---|
|data.py|校验日历、标识、OHLC、成交量、覆盖和哈希；保留缺失报价|不回填上市前历史，不静默删股|
|features.py|滚动趋势、突破、动量、波动、横截面广度|不读未来行，不用全期股票排名|
|strategy.py|可解释目标权重、风险状态机、持仓迟滞|不产生真实券商订单|
|execution.py|研究手续费、最低申报量、涨跌幅近似规则|不宣称覆盖全部证券状态和券商规则|
|engine.py|信号延迟、先卖后买、现金与持仓守恒、逐笔记录|不假设收盘信号能在当天执行|
|evidence.py|指标、完整性校验、不可覆盖输出、身份核对|不把完整文件解释成经济验收通过|
|cli.py|audit、backtest、inspect、verify 四个离线命令|不接管账户，不发送订单|

## 独立性与参考范围

参考 `trades` 的 `chatgpt/turtle_dual`（海龟、均线与 ATR 多组合）、`trae/glmcsm`（截面动量和组合约束）、`workbuddy/track_trend`（趋势跟踪与保护）、`dumate/momentum_rotation`（趋势动量轮动与风险状态）。这些是研究问题的参考，不是实现底座。生产包不导入它们的模块，不继承它们的引擎，不复制其函数和股票专用调参表。原生 harness 在隔离进程中只修改输入、股票池、区间与初始资金，保留对方原始策略和执行规则。

四套方法的优点不能通过叠加规则自动兼得。更快降险与更长趋势持有存在误报、滞后和换手成本；本系统提供可测量的取舍，不宣称已经融合所有优势。

## 趋势与持仓

短均线要求 `fast` 个历史观测，长均线从同样数量的观测逐步增长至 `slow`。不读 2023 年以前的数据；新股从首个真实报价开始积累历史，最近短窗至少 80% 有有效报价且当日有效才具备就绪条件。

入场要求短均线高于长均线、价格高于短均线、短期收益为正，并满足短窗突破或最近五日有四日位于短均线上方。排序分数为短、中、长三个周期对数收益的加权和，再除以波动率平方根；权重固定为 0.2、0.3、0.5。长历史不足时只能使用已经观察到的上市后收益，不使用未来数据补齐。

现有持仓排序享有 2 倍正分数优先，但不是永久持有豁免。入选成员不变且没有风险恢复时，不因分数噪声反复调仓；集中度、波动、风险预算和退出条件仍优先。分配按分数平方根加权并逐次填充剩余限额，不把受限权重再次归一化到超限。

退出由长趋势破坏、ATR 跟踪阈值伴随短趋势破坏，或个股突发下跌触发。策略只在收盘后决定，不模拟盘中按理想止损价逃顶。

## 风险与恢复

横截面单日冲击、三日累计冲击、组合净值回撤伴随新增损失、整体趋势和上涨广度恶化，分别构成不同原因码。市场偏弱本身只是观察，不机械否定仍保持趋势的个股。风险判断不使用固定光通信龙头观察篮子；从股票池移除标的，也从其信号和横截面观察中移除。

风险预算下降立即生效于信号，最早下一交易日模拟卖出；恢复要求新的可观察确认，先恢复不超过半仓，再经过一次确认间隔恢复全预算。重新投入风险资本时重置的是干预周期参考峰值，不是报告净值或历史回撤。`risk_drawdown` 是触发条件，不是最大亏损保证；跳空、跌停、停牌、流动性以及慢跌均可能令实际回撤超过该值。

波动预算使用加权单股波动的完全正相关上界，刻意不依赖不稳定的小样本相关矩阵。代价是可能长期降低牛市仓位。目标权重允许声明的普通漂移区间；真正降险不使用普通调仓门槛来拦截必要减仓。

## 全部可配置参数

`config/research.json` 是冻结选优候选的显式配置；Python API 默认值与其保持一致。更改任一项都会产生新研究身份，不继承已有经济结论。

|参数|当前值|意义与代价|
|---|---:|---|
|fast|10|短趋势、波动和快速动量窗口；小值更敏感且容易反复|
|slow|40|长趋势和跟踪峰值窗口；长值更迟钝|
|max_positions|2|目标最多持有数；不是至少持有数|
|rebalance|10|定期筛选间隔；强制退出和降险不等待这个周期|
|single_cap|0.55|单股分配上限；单股股票池允许 100%，普通漂移另有 trade_band|
|sector_cap|0.75|多行业池的子行业预算；只有一个行业时允许全行业预算|
|trade_band|0.08|目标变化与普通漂移迟滞；不能据此取消保护性退出|
|stop_atr|6.0|跟踪退出 ATR 倍数；不是保证成交价|
|target_vol|0.80|年化波动预算上限，不是预期年化收益|
|shock_z|2.5|冲击相对于事前波动的倍数阈值|
|risk_drawdown|0.18|风险干预参考回撤；不等于最终最大回撤上限|
|recovery|3|每一级风险恢复需要的连续确认次数|
|initial_cash|2000000|统一初始资金，单位人民币元|
|commission_bps|2.5|研究佣金率，另有每笔最低 5 元假设|
|slippage_bps|10|每次成交的不利滑点，成本压力场景按倍数放大|
|max_adv|0.005|按此前最多 20 日平均成交额估算的单股成交容量比例|

还有写在源码中的全局规则常量，例如五日持续性、80% 有效报价、最低波动、普通订单 1% 净值门槛、冲击绝对下限和价格限制容差。它们同样影响行为，不能把“16 个配置字段”宣传成“只有 16 个影响策略的数值”。修改这些常量也需要新身份和重新检验。

## 账本与执行限制

以复权经济单位记账，原始价格仅用于估算申报数量和容量。这个模型不是实际股数、现金分红、送转股和税费逐事件账本。不能从回放持仓推断用户真实持仓，也不能把经济单位直接转换为券商交易指令。

先卖后买，仅使用信号日前的成交额估算开盘容量。没有下一日开盘报价、开盘近似涨跌停限制、现金不足或最低申报量不满足时记录阻塞，不制造成交。滑点向不利方向计入，手续费逐笔扣减；不强制期末清仓。保护性清仓不受普通 1% 金额门槛限制，但仍受可成交性限制。

申报数量、涨跌幅和过户费只是普通状态的研究近似，未完整覆盖 ST、上市初期特殊规则、公司行动参考价、退市和涨跌停排队。科创板普通申报最低 200 股、超出部分按 1 股递增的说明见上交所投教资料（https://edu.sse.com.cn/tib/ysptj/c/4768085.shtml）；印花税自 2023-08-28 减半依据财政部税务总局 2023 年第 39 号公告（https://m.mof.gov.cn/czxw/202308/t20230827_3904226.htm）。日期分段只服务费用制度，不服务择时。真实费用必须按账户、证券和交易日核验。

## 工程质量边界

保持单进程、显式数据对象和小型离线入口；避免服务化、插件式策略框架、大量配置兼容和多层 CI。必要测试覆盖未来数据不影响前缀、现金守恒、先后执行、保护性退出、组合顺序确定性、恢复、数据和证据身份。没有宣称已达到独立第三方审计或业界顶尖认证；公司行动账本和公平对照仍是明确缺口。
