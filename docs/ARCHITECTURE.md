# 架构、默认策略与参数

## 生产路径

生产包保持单一依赖方向：`data → engine → passive → evidence / cli`。`research/` 只负责冻结复现、参考比较和证据，不参与默认生产决策。

默认策略 `passive_ownership` 复用 `engine.run(..., benchmark="buy_hold")` 的同一账户与执行状态机，不另写第二套回测器。生产适配器只改变策略身份元数据，经济执行保持共享。显式 `buy_hold`/`equal_weight` 仍是研究 benchmark，不是第二条生产策略。

## Passive ownership 语义

对调用时给定的股票集合，账户以统一初始资金启动，初始预算按该集合等分。上市前无报价、开盘涨跌停近似约束、缺少事前成交容量、整手限制或现金不足时，未完成买入会在后续可执行开盘继续尝试。已经买入的持仓不为恢复等权而卖出，也不因趋势分数、行业权重或账户风险状态主动减仓。

删除某证券意味着重新定义输入股票集合；冻结移除案例仍以完整 200 万元账户在剩余集合上启动。不能把它改写成永久固定 34 份并删除对应本金的另一种账户定义。

## 执行与账户

所有信号最早下一交易日开盘执行。容量只使用信号日前可知的历史成交额；开盘报价、涨跌幅近似、整手、现金、手续费和滑点共同约束成交。普通成交在容量/整手/现金裁剪后仍需达到 1% 开盘净值的执行金额门槛。账户始终要求现金不透支、持仓不为负、净值有限且为正。

账本使用复权经济单位，原始价格用于估计申报数量和容量。它不是实际股数、现金分红、送转股和逐事件税费账本，因此不能直接作为券商订单。

## 生产配置

`config/production.json` 只允许四个实际影响 passive 执行的参数：

|参数|默认值|作用|
|---|---:|---|
|initial_cash|2000000|初始账户资金，人民币元|
|commission_bps|2.5|研究佣金，另有每笔最低费用假设|
|slippage_bps|10|每次成交的不利滑点|
|max_adv|0.005|按此前最多 20 日平均成交额估算的单股容量比例|

`Config` 中仍存在 active research 所需的趋势/风险字段，因为共享引擎和历史研究 API 需要保持可复现；生产 CLI 不暴露这些字段，并在生产配置中出现时直接报错。它们不控制 passive 的成员选择、卖出或再平衡。

## 风险边界

默认策略不主动止损、择时卖出或调仓，因此可能出现大幅回撤。风险指标继续在回放与 `inspect` 中披露，但当前生产选择以收益优先，不将回撤或压力窗口表现作为晋级门槛。该优先级不改变账户安全、因果时钟、成本、流动性和数据完整性要求。

历史回测不构成未来收益保证。
