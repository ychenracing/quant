# Tail-risk authority: implementation and exact evidence

This continues the existing risk_reliability_contract.json registered before measurement. There are exactly two boolean candidates, no model refitting, no forecast ranking, no price-only extra candidate, and no change to old selectors, costs, source families, execution rules or main. The concurrent funded-risk contract and support-budget work remain separate and intact.

At each signal close, the new module first makes only the newly matured twenty-session outcomes available. Its historical class reference follows the existing learner training convention in nonlinear.training: causal feature-valid observations, equal aggregate contribution per date before decay, half-life120, at most504 mature feature sessions, at least40 distinct valid dates, rescaling total observation weight to that number of dates, and one Laplace count per class. Trading-ready quoted names are used to score original issued forecasts; feature-training validity is not silently replaced with the later trade admission gate. The reference at issuance is preserved and never reconstructed using subsequent outcomes. Errors are stored at their maturity date. Latest120 issuance sessions and forty scored dates determine prospective authority; unavailable evidence or zero reference error grants none.
